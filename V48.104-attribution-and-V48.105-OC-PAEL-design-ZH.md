# V48.104 OC-NICR 可靠性归因与 V48.105 OC-PAEL 设计

## 1. 结论摘要

V48.104 hotfix 后的正式结果工程可靠，可做科学归因。Pipeline/runtime/JSON/PT/audits SHA 闭合；实际仅训练历史最后一个 Stage-I Transformer block（444,864 参数），V48.103 FCSS readout、其他 Stage-I、root decoder、source、planner 全冻结。初始化函数等同 V48.103，nominal memory bit-exact identity 为真，state metrics 在 1e-7 内与 V48.103 完全一致。

严格按预注册，V48.104 是 **formal STOP**：State GO，Support STOP，Reserve STOP，因此既不是 Full GO，也不是两条预注册 Partial-GO 分支。

最关键的正结论是：V48.104 同时保持 nominal state 且使两条 candidate-minus-nominal response loss 都下降，证明 V48.103 的 state/response 优化干扰可以通过“结构性 nominal invariance + response-only objective”消除。失败已经从“状态被 action learning 破坏”进一步收紧为“action-response latent direction 无法跨 variant / dev-certificate / Near-Contact 稳定迁移”。

## 2. 可靠性审计

- Runtime `valid=true / attribution_ready=true / errors=[]`，hotfix active source SHA 与上传 drop-in 一致。
- Pipeline manifest 中 balanced/precision JSON/PT、comparison、runtime SHA 与单独上传文件逐字节一致；audits.zip 内同样逐字节一致。
- 两个 PT 仅包含 `adapted_last_block_state` 的 12 组 Transformer 参数，总数 444,864；没有 readout/source/planner/root-decoder 参数。
- `initial_v103_function_identity=true`。
- `nominal_memory_exact_identity=true`，hotfix 采用先 `residual-anchor` 再回加 base 的 bit-exact centering。
- `prelast_reconstruction_max_abs=0.0`。
- `state_metrics_exact_v103.valid=true`，tolerance=1e-7。
- 四个 evaluation role 均 `valid=true`，无 duplicate nominal / missing nominal。
- `test_roots_read=false`，teacher metadata 未进入模型。

因此没有工程 blocker，不需要重跑 V48.104。

## 3. 严格预注册判决

State GO：6/8，4/4 role 覆盖。

Support-action：4/8 absolute action-gate cells，top-1 material 7/8，正式 STOP。

Reserve/debt：5/8 absolute action-gate cells，top-1 material 6/8，正式 STOP。

因此 `NOMINAL_INVARIANT_CONTROL_REFINEMENT_STOP`。按照预注册 branch taxonomy，State-only 正证据不构成 Partial GO；下一步必须关闭 last-block refinement family，进入 pre-last-token action-equivariance/localization audit。

## 4. V48.104 真正解决了什么

V48.103 的关键冲突是 absolute support 变好而 delta-support 变坏。V48.104 去掉 absolute-state/static loss，只训练两条 response loss，并让 nominal memory 对任意参数都严格等于历史 nominal memory。

Balanced dev：

- delta-reserve 0.30120 -> 0.26795，约 -11.0%；
- delta-support 0.35915 -> 0.32260，约 -10.2%。

Precision dev：

- delta-reserve 0.30098 -> 0.26675，约 -11.4%；
- delta-support 0.35342 -> 0.32432，约 -8.2%。

两套 variant 均 best_epoch=59/60，loss 单调改善、grad norm 稳定衰减，说明 response learning 真实发生。它不再牺牲 static state。

这支持一个更强结论：

`static sufficiency != control sufficiency`

`parameter factorization != representation factorization`

`response-loss reduction != cross-distribution action equivariance`。

Control-sufficient representation 必须同时满足：

1. nominal sufficient statistic 对 action-response adaptation 不变；
2. candidate-induced response 可辨识；
3. response orientation 在 role / variant / dev-certificate 之间稳定。

## 5. Near

Nominal state 已不再是 bottleneck：dev-Near state 精确保持 V48.103（balanced 1.00，precision 0.857）。

Support：balanced dev-Near 0.508 -> 0.656，certificate-Near 0.691 -> 0.836；precision certificate-Near 0.745 -> 0.782，但 precision dev-Near 0.609 -> 0.563。

因此 Near 的瓶颈已从“如何同时保护 state 和 response”收紧为：

**在 nominal state 已严格保护的条件下，形成 variant-independent、跨 split 稳定的 positive-support response direction。**

V48.104 已经把 V48.101 的 action learning 与 V48.103 的 state preservation 在优化层面组合起来，但尚未把它们变成统一、稳定的 control-sufficient coordinate。

## 6. Contact

Contact reserve 的 generalization 有实质进步：

- balanced certificate-Contact reserve 0.306 -> 0.486；
- precision certificate-Contact reserve 0.319 -> 0.514；
- 两者 true-minus-shuffled 均约 +0.153，top1 lift +0.25。

同时 dev-Contact reserve 从 0.750/0.740 降到 0.641/0.703。结果是 dev-certificate AUC gap 从约 0.444/0.420 收缩到 0.155/0.189（约缩小 65%/55%）。

这说明 V48.104 的 nominal-invariant response refinement 的确在修 cross-split debt-response generalization，而不是完全错误的方向；但 certificate-Contact 仍低于 0.65，因此只能作为强正信号，不能 promotion 为完成机制。

当前 Contact 主缺陷进一步收紧为：

**signed debt response 的绝对 separability / orientation 尚未达到跨 split control-sufficiency；不是 static Contact recognition。**

## 7. Promotion / Main Stack

值得 promotion 为“硬结构原则 / scaffold”：

- exact nominal-memory preservation by counterfactual centering；
- candidate-minus-nominal response semantics；
- nominal state 结构保护后采用 response-only representation learning；
- support establishment 与 signed reserve/debt 分轴验证 + within-group permutation null。

不 promotion V48.104 concrete last-block NICR module，因为 Support/Reserve 都 STOP。

Main Stack 暂不增加 version-specific block。继续保持 OC-MERO + actuator-realizable executable recovery + counterfactual equivalence-partition transport + identifiability-before-capacity + support-establishment/signed reserve-debt + recovery base-state chart + RIFA。若未来 response action-equivariance Full GO，可用更上位的 `nominal-invariant control-sufficient recovery representation` 替换较弱的 `recovery base-state chart` 表述，而不是继续叠版本组件。

## 8. 为什么下一步必须是 audit

V48.104 证明最后一个 block 能降低 response regression error，却不能闭合跨 cell action gate。继续训练更多 epoch、换 LR、增加 head/depth、解冻更多 block，只会重新把“信息在 upstream 是否存在”和“transport 是否错误”混在一起。

下一步应回答：

**最后一个 Stage-I block 之前，是否已经存在可迁移的 candidate-minus-nominal support/reserve statistic；它是否集中在 control + scene interaction tokens，而不是 nominal ego/history nuisance coordinates？**

## 9. V48.105 OC-PAEL

全称：Observation-Consistent Pre-Last Action-Equivariance Localization Audit。

这是纯 audit：Stage-I / root decoder / source / planner 全部训练参数为 0。

V48.105 在历史最后一个 Stage-I block 之前的 token set `H^-(a)` 上复用 V48.102 **完全相同**的 2880-D summary operator 和 linear-probe recipe：11 个固定 semantic token 原位保留，agent token set 仅做 mean/std/max/min；同样使用 V48.93 target-specific State/Support/Reserve semantics 和 within-group action permutation null。

这使 V48.105 与 V48.102 构成严格 layer-location ablation：

`V48.105 pre-last` vs `V48.102 historical final Stage-I`。

如果 pre-last GO 而 final STOP，历史最后 block 是信息/transport bottleneck；如果 pre-last 也 STOP，问题已存在于更上游。

固定 localization partition：CLS；ego/history；control；scene-context（agent-summary/BEV/route/map/dynamics）；agent-set moments。另预注册唯一 action-interaction subspace：`control + scene-context + agents`，排除 CLS/ego-history。没有 best-token post-hoc selection。

Per-group action-energy share 与 linear CKA 仅作为诊断，不替代 AUC gates。CKA 用于观察 representation 与 response labels 的线性几何依赖，不作为新的优化目标。

## 10. V48.105 gates / branch

Global pre-last State/Support/Reserve 使用 V48.100--104 同一绝对 gate。

Action-interaction subspace 的 Support/Reserve 也用同一 action gate，但仅用于定位，不可替代 global Full GO。

Branch：

1. Global State+Support+Reserve GO -> 关闭 encoder training，下一步只允许 direct nominal-invariant pre-last response transport。
2. State+Support GO / Reserve STOP -> 只处理 signed reserve/debt localization。
3. State+Reserve GO / Support STOP -> 只处理 support establishment localization。
4. Global response STOP、但固定 action-interaction Support+Reserve 都 GO -> 说明信息局部充分但被 nuisance dilution；只允许 fixed-subspace nominal-invariant response transport。
5. 其他 -> pre-last action equivariance 不充分，关闭该 readout family；下一步只向前移动一个 block 做同一 action-interaction audit，不直接 broad encoder training。

## 11. 理论依据

- DeepMDP：控制表征应对 reward 与 latent transition distribution 保持预测约束，支持“静态 state 好并不足够”。
- Action-Sufficient State Representation：POMDP 中 representation 应保留 downstream action selection 真正需要的充分信息，而非任意 observation compression。
- Action-conditional self-predictive RL（AISTATS 2025）：action-conditioned latent dynamics 是 representation objective 的核心对象。
- EqR（ICML 2022）：action transformation 与 latent transformation 的可预测/等变关系可以作为 representation inductive bias。
- CKA（ICML 2019）：可用于比较/定位不同层 representation geometry；V48.105 只把 CKA 用于诊断，不把它变成 post-hoc selection gate。
- Action-bisimulation encoding（RLC 2024）：强调 controllability/action relevance 应成为 representation 的不变结构，而非只依赖静态观测相关性。

## 12. 禁止项

V48.105 禁止：V48.104 last-block LR/epoch/head/depth/residual scale sweep；V48.103 readout capacity 扩张；joint readout+block training；best token/group post-hoc selection；regime-specific token router；source/boundary transport/relative ranker/broad encoder/dataset reconstruction。
