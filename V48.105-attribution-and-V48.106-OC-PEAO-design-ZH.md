## 2. V48.105 正式判决

正式状态：`PRELAST_ACTION_EQUIVARIANCE_LOCALIZATION_STOP`。

- State：STOP，0/8 positive cells；
- Support：STOP，仅 balanced/precision 的 dev-Near 2/8 positive；
- Reserve：STOP，0/8 positive；
- 固定 1920-D action-interaction subspace：Support STOP，Reserve STOP；
- 因此不是 Full GO，也不是任何 preregistered partial GO。

V48.105 是 audit-only，所以它没有直接提升 planner performance；它的价值是进一步定位 defect layer。

## 3. 关键实验现象

### 3.1 pre-last 不是一个已经 control-sufficient、只被最后一层破坏的表示

相对 V48.102 final Stage-I：

- dev-Near support：0.8125 -> 0.671875；
- certificate-Near support：0.618 -> 0.473；
- dev-Near reserve：0.75 -> **0.0**；
- certificate-Contact State：0.732 -> 0.232。

因此历史最后一个 Stage-I block 不只是破坏信息，它还负责构造/旋转部分 recovery semantics。

### 3.2 “association != signed orientation”

最强证据来自 reserve/control token：

- control token 平均 action-energy share ≈ 21%；
- reserve 的 control-token mean CKA-minus-shuffled ≈ +0.375；
- 8/8 cells 的 reserve control CKA-minus-shuffled 为正；
- dev-Near reserve 的 control token label CKA ≈ 0.958、shuffle ≈ 0.033；
- 但同一 held-out cell 的全局 reserve AUC = 0.0、margin = -0.75、top1 lift = -1.0。

Linear CKA 衡量的是表示/标签 Gram 几何关联，符号翻转不会改变这种 magnitude/similarity 指标。因此高 CKA 不能证明 train 与 held-out 使用同一 signed action direction。V48.105 的现象更符合“信息/相关性存在，但 orientation 在 population 间翻转或被 confound”。

### 3.3 固定 action-interaction subspace 不充分

预注册的 `control + scene_context + agents` 1920-D 子空间两条 action axis 全部 STOP。某些 cell raw AUC 很高，例如 certificate-Contact reserve ≈0.792，但 shuffle AUC≈0.764、top1 lift=-0.5，因此不能当作真实 transferable response。

### 3.4 action energy 的主要载体不是 scene context

V48.105 的 architecture-defined localization 显示：

- support：ego/history/prefix 约 57%，control 约 22%，agents 约 19%，scene-context <1%；
- reserve：ego/history/prefix 约 60%，control 约 21%，agents 约 16%，scene-context <1%。

这里的 ego/history 组包含 ego、prefix parameters、macro/scalars、prefix states。由于 prefix/state/control 本身承载 candidate rollout，这不是简单 nuisance；但该现象只作为定位证据，不允许结果后选 token subset。

## 4. 因果链进一步收紧

当前证据链可写成：

1. V48.100：static recovery state 可学习；
2. V48.101：action-sensitive transport 可恢复 support，但会破坏 static state；
3. V48.102：Stage-I final memory 有局部 action information，但没有统一 State+Support+Reserve statistic；
4. V48.103：参数 factorization 可以保护 state，但 frozen latent geometry 不自动 action-equivariant；
5. V48.104：hard nominal invariance + response-only learning 可以同时降低 delta-support / delta-reserve，而不动 static state；
6. V48.105：pre-last 表示存在强 action association，但 signed held-out orientation 不稳定。

因此长期理论主线进一步强化为：

`static sufficiency != control sufficiency`

`parameter factorization != representation factorization`

`response-loss reduction != cross-distribution control sufficiency`

`action-response association != signed action equivariance`。

## 5. Near / Contact 当前 bottleneck

### Near

Nominal state preservation 已基本解决，不再是第一 bottleneck。pre-last dev-Near support 是真实正向 cell（AUC≈0.672、margin≈+0.188、top1 lift≈+0.4），说明 support establishment direction 在局部存在；但 reserve 在 pre-last 完全反向（AUC=0）。

Near 当前 bottleneck：

> 在已保护 nominal state 的前提下，让 support establishment 与 positive reserve response 使用跨 variant / split 稳定的 **同号 signed orientation**。

### Contact

pre-last dev-Contact support 有局部排序（AUC≈0.619、margin≈+0.136、top1 lift≈+0.333），但 certificate-Contact support 低于 null。Reserve 的 certificate raw AUC≈0.75，但 margin≤0 且 top1 为负。

Contact 当前 bottleneck：

> 去除 train/dev/certificate 中的 response confounding，使 signed recovery-debt repayment direction 真正跨 split 迁移。

Near 与 Contact 仍由同一个 mathematical object 统一：candidate-minus-nominal signed recovery response。Near 要把 response 推向正 support/reserve；Contact 要沿同一个正方向偿还负 debt。

## 6. Promotion / Main Stack

V48.105 是 audit，不进入 production Main Stack。

应保留/提升为长期 scientific protocol：

- high CKA / high energy 不能作为 action equivariance 证据；
- 必须同时检查 signed transfer、within-group permutation null 和 top1 ordering；
- 在开 capacity 前继续 layer-localization。

Main Stack 继续不变：

`OC-MERO + actuator-realizable executable recovery + counterfactual equivalence-partition transport + identifiability before capacity + support-establishment/signed reserve-debt + recovery base-state chart + RIFA`。

候选的高层 replacement 仍是 `nominal-invariant control-sufficient recovery representation`，只有未来 State+Support+Reserve Full GO 后才能替换 recovery base-state chart。

## 7. V48.106 OC-PEAO

全称：**Observation-Consistent Pre-Encoder Action-Orientation Audit**。

### 7.1 为什么必须是 audit

V48.105 已预注册：pre-last STOP 后只能向前移动一个 Transformer block 做 action-interaction audit；不得训练模型或开 source。历史 Stage-I 只有两层 Transformer，因此 V48.106 的 primary representation 是第一层 Transformer **之前**的 projected semantic token set。

### 7.2 Primary gate 完全不变

V48.106 继续复用：

- V48.102 deterministic 2880-D summary；
- 11 fixed semantic token positions + agent mean/std/max/min；
- 相同 `state / delta / delta*(1+tanh(state))` features；
- 相同 train population / target-specific State-Support-Reserve semantics；
- 相同 linear probe recipe；
- 相同 within-group action permutation null；
- V48.105 同一个 1920-D fixed action-interaction subspace；
- 相同 AUC/top1/cross-role GO gates。

因此 V48.106 不做任何 token 后选，也不改变 capacity。

### 7.3 新增 signed-orientation diagnostic

V48.105 的 CKA/AUC 冲突说明 CKA 看不到符号翻转。V48.106 新增 diagnostic-only train-to-heldout orientation cosine：

- 使用 train-only mean/std 标准化；
- train direction = positive class mean - negative class mean；
- held-out direction 同样计算；
- cosine +1 表示 same orientation，-1 表示 sign reversal；
- 同时计算 within-group shuffled orientation；
- 对固定 `cls / ego_history / control / scene_context / agents / action_interaction` 六组全部报告；
- 该指标**绝不参与 branching**，Primary AUC/top1 gate 不变。

这能把“强 association 但方向翻转”与“本来就是同向 transferable response”明确区分。

### 7.4 Branches

1. global State+Support+Reserve Full GO：关闭 encoder training，授权一次 direct nominal-invariant input-anchored response transport；
2. State+Support GO / Reserve STOP：只处理 signed reserve/debt orientation；
3. State+Reserve GO / Support STOP：只处理 support-establishment orientation；
4. global fail，但同一个 fixed action-interaction subspace Support+Reserve GO：固定子空间 transport，不允许 learned router；
5. 其余情况：`PREENCODER_ACTION_ORIENTATION_STOP`。这意味着 frozen Stage-I 从最早输入到 final 都没有暴露统一 transferable response；下一步才允许训练**第一 Stage-I Transformer block**的 nominal-invariant action-orientation objective，历史 final block、FCSS、source/planner 继续冻结。

## 8. 理论依据

- EqR（Mondal et al., ICML 2022）：action equivariance应被当作 latent transition / representation 的结构约束，而不是仅靠静态表示；
- Kornblith et al.（ICML 2019）：CKA 是 representation similarity 指标；其 Gram/squared alignment 形式不能表达我们需要的 signed causal orientation，因此 V48.105 的高 CKA 不足以说明 response direction 正确；
- Khetarpal et al.（AISTATS 2025）：action-conditional self-predictive representation 强调 action-conditioned dynamics；
- Action-bisimulation（RLC/RLJ 2024）：控制表示应保留真正与 action controllability 相关的状态因素，而不是环境特有的相关性。

这些文献提供方向，但 V48.100--105 的内部实验链才是当前算法分支的直接因果依据。
