四个 wave：

A_three_factor_joint
  旧三风险因子 + 联合训练，用于验证 v48.26 表示合同。

B_five_factor_joint
  A + hard-rule/harm-proxy 两个不可补偿风险因子。

C_five_factor_two_stage_regression
  B + factor/admission 两阶段解耦 + deployment-exact safe-utility regression。

D_full_factor_physics_bridge
  C + deployment-exact safe-utility listwise 和 frontier contrast。

调度：
- 每个 wave：Balanced 独占 GPU0，Precision 独占 GPU1；
- 一张卡同时只运行一个任务；
- 每张 GPU 共四个任务；最大并发 2。

七、结果判读
------------

1. 先看 development rule：
   - `dev_frozen_rule_*_v48.json` 是否存在正式 `rule`；
   - `source_rule_satisfied_dev_constraints=true`；
   - rejection_kind 是否为 development_rule_fit_rejection。

2. 再看完整 certificate：
   - proposal oracle 是否继续 feasible；
   - selected、safe-positive precision/LCB、harmful UCB、recall；
   - selected teacher advantage mean；
   - macro concentration。

3. Near 离线目标：
   - Precision 的 conditional harm AUC 与低 false-switch 应保留；
   - Balanced A/B 中的正 mean advantage 应由 C/D 保留或提高；
   - safe-positive recall > 0，selected harmful 显著下降；
   - correlation 转正、top-1 regret 下降。

4. Contact 离线目标：
   - positive selected 不再只有 1；
   - harmful selected rate 从约 44%–46% 大幅下降；
   - selected teacher advantage mean 转正；
   - correlation 转正、safe-positive AUC/harm AUC 同时改善；
   - macro concentration 受控。

5. Near shadow：
   - collision/overlap 非劣；
   - minimum/terminal clearance 和 TTC 提升；
   - near/critical exposure duration、episode、longest run 和 deficit AUC 降低；
   - intervention burst、route progression、jerk、yaw-rate 合格。

6. Contact shadow：
   - secondary/re-contact、overlap duration/longest run 降低；
   - free-space AUC、terminal clearance、sustained escape、stable-stop quality 提升；
   - time-to-escape/time-to-stable-stop 缩短；
   - offroad、route progression、jerk、yaw-rate 和干预负担受控。

关键归因：

- B>A：五因子 harm 表示缺失是主要瓶颈。
- C>B：联合稀疏 admission 梯度污染 factor learning。
- D>C：execution-exact listwise/frontier 有额外价值。
- 离线改善但 shadow 不改善：PCD teacher 未充分表达时间恢复过程；下一轮应预注册 candidate-level physical rollout auxiliary labels。
- dev rule 有效、certificate 失败：泛化或有限样本问题，不得读取 test/stress。
- proposal oracle 失败：proposal/标签/gate 合同结构问题；不要继续重复 calibrator。

------------
