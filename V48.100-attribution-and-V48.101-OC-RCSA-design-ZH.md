## 1. 对论文、数据、代码主线的理解

### 1.1 论文 idea / motivation

论文最强的主线不是普通 collision classifier，而是 **oracle-to-deployable recoverability gap**：如果多个 latent future 在部署时拥有相同/不可区分 observation，那么不能让每个 hidden root 暗中各自选择 recovery option；deployable planner 必须在 observation-compatible information pattern 下共享合法 recovery decision。

OC-MERO 用 observation-compatible root 集合、fixed-option inner lower-tail aggregation、observation-class choice 和 outer lower-tail aggregation定义 deployable recoverability。RIFA 将 relative recovery evidence 与 absolute deployable feasibility admission 隔离，避免 source 与 ranker 相互污染。

Safe / Near-contact / Contact 是同一个 planner 的 supervision/evaluation strata，而不是 runtime regime router：

- Safe：non-interference / nominal utility；
- Near：在 zero boundary 前保持 positive recovery headroom、建立 shared support；
- Contact：负 recovery debt 的偿还、finite-time/persistent re-entry、secondary/re-contact avoidance。

### 1.2 数据集性质

不重构数据。reports 中正式的 train/val/calibration/test × Safe/Near/Contact 12 个桶满足 finite/schema/OC-MERO recomputation 等检查，之前 audit 也显示 scene leakage 为空。

代表性 val 数据：

| Regime | samples | negative-deployable | oracle artifact |
|---|---:|---:|---:|
| Safe | 2,328 | 7.35% | 0% |
| Near | 3,445 | 50.42% | 24.59% |
| Contact | 6,477 | 46.15% | 21.86% |

Near/Contact 还有明显 observation-alias conflict 和 recovery-option diversity，适合研究 oracle-to-deployable gap、absolute source 和 witness selectivity；Safe 没有 oracle artifact，但仍有 deployable negative，因此能作为统一 policy 的 non-interference bucket。

投稿层面仍有 provenance debt：reports 支持 Waymax runtime，但 `supports_womd_primary_claim=false`。这不影响当前算法归因，但最终若写“WOMD-primary”需要补 provenance evidence 或收紧措辞为 WOMD-derived / Waymax-based construction。

### 1.3 当前 Main Stack

当前应稳定维持：

1. OC-MERO observation-consistent deployability；
2. actuator-realizable executable recovery；
3. counterfactual equivalence-partition transport；
4. identifiability before capacity；
5. support-establishment / signed reserve-debt semantics；
6. recovery base-state chart；
7. RIFA role isolation。

V48.99 Jacobian 不进入 Main；V48.100 也没有 Full GO，因此不能把 “control-sufficient recovery representation” promotion 进 Main。

## 4. V48.100 真正学到了什么

### 4.1 静态 state chart：应该 promotion / 强保留

V48.97 的 base-state chart 已有正证据；V48.100 进一步做到 State 8/8。当前可以更有把握地说：

> shared support state + signed reserve/debt 是一个跨 Near/Contact 有用的低维 recovery semantic chart。

这属于 Main Stack 的稳定骨架。

### 4.2 Absolute support 学得很好，candidate-induced support 几乎没学

Dev normalized Huber 从 epoch 0 → 59：

| Term | Balanced | Precision |
|---|---:|---:|
| absolute support | **-27.3%** | **-27.5%** |
| delta support | **-0.96%** | **-0.81%** |
| absolute reserve | -3.33% | -3.20% |
| delta reserve | **-7.29%** | **-7.00%** |

这是本轮最关键的因果图景：

```text
static support/state representation      ✓
continuous reserve action dynamics       partial ✓
discrete support-establishment dynamics  ✗
```

### 4.3 Query anchor 已经发生大幅位移，但仍没解决 support

```text
||q0||      ≈ 1.783
||delta_q|| ≈ 2.018–2.019
max |delta_q| ≈ 0.074
```

这不是说 query “饱和”，但说明 V48.100 已经允许 root anchors 大幅移动；继续把问题归结成“query 再挪一点”缺乏因果依据。

### 4.4 为什么不能说 frozen roots 没有 action information

V48.96 已经给过 support-action observability 的正证据。所以当前更合理的解释不是：

> structured memory/root 完全没有 support-action 信息。

而是：

> **该信息没有通过冻结的 observation/action-memory → root cross-attention metric，被组织成与 V48.100 semantic chart 一致的 shared-support transition。**

## 6. Near-contact / Contact 的问题

### 6.1 Near-contact

Near 的核心不是再调 TTC/clearance threshold，而是：

> candidate 是否在部署时无法区分的 weak roots 上真正建立 shared recovery support，并保持正 recovery headroom。

V48.100 dev-Near support AUC 只有 0.398/0.438；虽然 top1 lift +0.2，说明局部 scene 内 action ordering 有信息，但跨 group semantic coordinate不稳定。

Reserve 的 dev-Near balanced AUC=1.0，但 precision=0.5，且只有 6 rows / 1 powered group。因此不能把它写成 reserve 已解决。

### 6.2 Contact

Contact 的 reserve/debt signal 比 Near 更稳定：dev-Contact AUC 0.734–0.776，top1 lift +0.4/+0.6；但 certificate-Contact reserve AUC 只有 0.417。

所以 Contact 当前不是“完全不会 recovery”，而是：

> dev 上存在 debt-repayment ordering，但跨 certificate 的 signed-debt coordinate 仍不稳；support 也只有中等水平。

统一目标仍应是：

```text
Near    = preserve reserve + establish support
Contact = repay debt + sustain support/re-entry
```

而不是两个 policy。

## 10. 理论支撑

相关表示学习工作提供了三条与当前机制一致的高层原则：

1. DeepMDP：控制有用的 latent representation 应与 latent dynamics/transition constraint 联合；仅静态压缩 observation 不足以保证 control sufficiency。
2. Action-conditional self-predictive representation：实际 action-conditioned prediction 与固定-policy/self-prediction并不等价，action dynamics 应显式进入 representation objective。
3. Action-Sufficient State Representations：在 partial observation 下，目标是学习对 downstream decision/control 足够的 state representation，而非保留所有 observation 信息。
4. Set Transformer：attention 是处理 permutation-invariant set interaction 的自然结构；这与 root-set/observation-compatible set semantics 相容。

这些文献支持 V48.101 的 representation-level方向，但 V48.101 的科学授权仍来自 V48.96→100 自身的因果证据链。

# 11. V48.101 OC-RCSA

全称：

**Observation-Consistent Root Cross-Attention Semantic Alignment**

### 11.1 Intervention

从每个 authoritative V48.100 checkpoint 开始：

```text
freeze:
  V48.100 query_delta       1536
  V48.100 semantic chart     770
  Stage-I / encoder
  root self-attention
  root FFN
  root logit head
  source / planner / RIFA relative path

train only:
  historical root_cross_attn = 148224 parameters
```

不改变 head 数、d_model、root 数、loss、semantic scales、population、threshold 或 dataset。

### 11.2 Objective

仍为 V48.100：

```text
1/4 * [
  normalized Huber(D, D*)
+ normalized Huber(R, R*)
+ normalized Huber(ΔD, ΔD*)
+ normalized Huber(ΔR, ΔR*)
]
```

semantic scale从 V48.100 state 原样复用。

### 11.3 为什么这次是干净因果实验

- 初始 cross-attention 是历史权重，没有 function jump；
- 在任何更新前必须复现 V48.100 held-out metrics（tol 1e-7）；
- query/chart 完全冻结，因此不是“再训 V48.100”；
- encoder/self-attn/FFN/logit/source不动；
- 唯一新自由度就是 memory-to-root cross-attention transport。

### 11.4 预注册 gate

State/Support/Reserve 继续使用 V48.100 原门槛，不放宽。

Full GO：

```text
State GO
AND Support GO
AND Reserve GO
```

只有 Full GO 授权一次 final fixed-capacity source。

分支：

- State+Reserve GO / Support STOP → one hybrid support guard；
- State+Support GO / Reserve STOP → one supported reserve-flow objective；
- 其他 STOP → 关闭 query/chart + cross-attention root-decoder semantic family，进入 Stage-I action-information transport sufficiency audit；不直接 broad retrain。
