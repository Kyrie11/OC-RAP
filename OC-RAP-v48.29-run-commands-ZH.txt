OC-RAP v48.29 VETO-RANK-PHYSICS-BRIDGE 执行指令
================================================

一、解压与环境
--------------

unzip -q OC-RAP-v48.29-VETO-RANK-PHYSICS-BRIDGE.zip
cd OC-RAP-v48.29-VETO-RANK-PHYSICS-BRIDGE
export PYTHONPATH="$PWD/src${PYTHONPATH:+:$PYTHONPATH}"

export OCRAP_ROOT=/data0/senzeyu2/dataset/OCRAP
export PROTOCOL_ROOT=$OCRAP_ROOT/calibration_v48_14_prism_4814
export CAL_SAFE=$OCRAP_ROOT/calibration_safe
export SOURCE_RUN=runs/ocrap_v48_13_terra_proxy_4801
export WOMD_VAL=/data0/senzeyu2/dataset/WOMD/waymo_open_dataset_motion_v_1_3_1/uncompressed/tf_example/validation/validation_tfexample.tfrecord@150
export GPU0=0
export GPU1=1

export OMP_NUM_THREADS=2
export MKL_NUM_THREADS=2
export OPENBLAS_NUM_THREADS=2
export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True,max_split_size_mb:128

二、先用 v48.29 修复并重跑现有 v48.28 dev-shadow（无需重训）
---------------------------------------------------------

export OUT=runs/ocrap_v48_28_provenance_margin_dedicated_4828

OUT="$OUT" \
OCRAP_ROOT="$OCRAP_ROOT" \
PROTOCOL_ROOT="$PROTOCOL_ROOT" \
DEV_SHADOW_WOMD_SOURCE="$WOMD_VAL" \
GPU0="$GPU0" GPU1="$GPU1" \
AUDIT_TARGETS=16 AUDIT_MAX_ROLLOUTS=8 AUDIT_MAX_STEPS=24 \
SHADOW_LABEL_MODE=fast SHADOW_AUDIT_LABELS=0 \
SHADOW_BOOTSTRAP=2000 CL_RESUME=0 \
bash scripts/repair_v48_28_dev_shadow_with_v48_29.sh \
  > "$OUT/dev_shadow_repair_v48_29_controller.log" 2>&1

cat "$OUT/dev_shadow_closed_loop_v48_29_repair/SHADOW_PROVENANCE_AUDIT.json"
cat "$OUT/dev_shadow_closed_loop_v48_29_repair/DEV_SHADOW_COMPLETE.json"
cat "$OUT/dev_shadow_closed_loop_v48_29_repair/balanced/SHADOW_RUNTIME_CONTRACT.json"
cat "$OUT/dev_shadow_closed_loop_v48_29_repair/precision/SHADOW_RUNTIME_CONTRACT.json"

要求：
- complete=true；
- runtime contract valid=true；
- Near/Contact gamma_rec 均大于 0；
- Contact post_contact_target=true；
- Contact contact_anchor_step 有限；
- metrics_valid=true。

三、运行 v48.29 主实验
---------------------

export OUTPUTDIR=runs/ocrap_v48_29_veto_rank_physics_dedicated_4829
mkdir -p "$OUTPUTDIR"

set +e
OUTPUTDIR="$OUTPUTDIR" \
OCRAP_ROOT="$OCRAP_ROOT" \
SOURCE_RUN="$SOURCE_RUN" \
PROTOCOL_ROOT="$PROTOCOL_ROOT" \
CAL_SAFE="$CAL_SAFE" \
GPU0="$GPU0" GPU1="$GPU1" \
PROPOSAL_TOP_K=3 \
EVIDENCE_COMPONENT_SCALE=6.0 \
EVIDENCE_ADMISSION_SCALE=2.0 \
ADMISSION_SAFE_UTILITY_REGRESSION_WEIGHT=0.75 \
ADMISSION_SAFE_HARD_NEGATIVE_WEIGHT=1.0 \
ADMISSION_SAFE_HARD_NEGATIVE_MARGIN=0.05 \
BATCH_SIZE=96 NUM_WORKERS=3 PREFETCH_FACTOR=3 \
FACTOR_EPOCHS=20 FACTOR_PATIENCE=6 \
ADMISSION_EPOCHS=18 ADMISSION_PATIENCE=6 \
EVIDENCE_ADAPT_LR=0.00015 \
bash scripts/run_v48_29_veto_rank_physics_dedicated.sh \
  > "$OUTPUTDIR/controller.log" 2>&1
RC=$?
set -e

echo "v48.29 main rc=$RC"
cat "$OUTPUTDIR/V48_29_COMPLETE.json"
cat "$OUTPUTDIR/GATE_FAILURE_DECOMPOSITION.json"

返回码：
- RC=0：Natural gate 有效通过，执行第五节授权 stress；
- RC=20：有效算法拒绝，执行第四节 fast dev-shadow 和第六节消融；
- RC=30：工程/协议/索引/checkpoint/certificate/runtime-contract 失败，只修工程，不做算法结论。

六、RC=20 后并发运行全部 8 个消融
--------------------------------

export ABLATION_ROOT=runs/ocrap_v48_29_veto_rank_physics_ablations_4829
mkdir -p "$ABLATION_ROOT"

ABLATION_ROOT="$ABLATION_ROOT" \
SOURCE_RUN="$SOURCE_RUN" \
OCRAP_ROOT="$OCRAP_ROOT" \
PROTOCOL_ROOT="$PROTOCOL_ROOT" \
CAL_SAFE="$CAL_SAFE" \
GPU0="$GPU0" GPU1="$GPU1" \
TASKS_PER_GPU=4 \
BATCH_SIZE=72 NUM_WORKERS=1 PREFETCH_FACTOR=2 \
FACTOR_EPOCHS=20 FACTOR_PATIENCE=6 \
ADMISSION_EPOCHS=18 ADMISSION_PATIENCE=6 \
EVIDENCE_ADAPT_LR=0.00015 \
bash scripts/run_v48_29_parallel_ablations.sh \
  > "$ABLATION_ROOT/controller.log" 2>&1

cat "$ABLATION_ROOT/TASK_GPU_ASSIGNMENT.txt"
cat "$ABLATION_ROOT/ABLATIONS_STATUS.json"

八个任务会同时启动：GPU0 四个 Balanced，GPU1 四个 Precision。
如 CPU/磁盘成为瓶颈，可改为 TASKS_PER_GPU=2 并分两批运行；显存不是主要限制。
