OC-RAP v48.13 TERRA 下一步运行指令
====================================

说明：
1. calibration_contact完成前，主实验、三seed和消融继续统一使用proxy_val_split。
2. 主实验和消融不要同时启动。四组消融会在脚本内部并发运行。
3. Natural gate阈值没有降低。只有生成NEXT_COMMANDS.txt才能运行Near/Contact stress closed-loop。
4. 下列路径沿用此前实验目录；先确认checkpoint实际存在。

0. 进入目录并确认旧任务退出
--------------------------
cd /path/to/OC-RAP-v48.13-TERRA
export PYTHONPATH="$PWD/src${PYTHONPATH:+:$PYTHONPATH}"

ps -ef | grep -E 'run_v48|train_ocrap|calibrate_policy|ocrap.cli' | grep -v grep || true
nvidia-smi

ASSET_ROOT=runs/ocrap_v48_8_shared_assets_4801
BAL_CKPT=runs/ocrap_v48_12_trident_proxy_4801/candidates/balanced/model_v48_trac_sr/best.pt
PREC_CKPT=runs/ocrap_v48_12_trident_proxy_4801/candidates/precision/model_v48_trac_sr/best.pt

for p in \
  "$BAL_CKPT" "$PREC_CKPT" \
  "$ASSET_ROOT/teacher_pcd_train_index.jsonl" \
  "$ASSET_ROOT/teacher_pcd_train_index_summary.json"; do
  [[ -f "$p" ]] || { echo "missing $p" >&2; exit 2; }
done
[[ -d "$ASSET_ROOT/dataset_splits" ]] || { echo "missing shared splits" >&2; exit 2; }

-------------------

CALIBRATION_SEED=4801 \
BUILD_TRAIN=0 BUILD_CALIBRATION=0 STRICT_TRAIN_DATA_GATE=0 \

分层判断：
- Proposal：positive-group oracle-best hit >=0.75，any-positive hit >=0.90。
- Evidence：Near benefit AUC >=0.70、Contact >=0.75；harm AUC >=0.60；correlation >=0.10。
- Natural gate：必须由原始controller生成NEXT_COMMANDS.txt。

4. 四组消融并发运行
------------------
不要与主实验同时运行。脚本在每个variant wave内同时启动四个任务：
- GPU0：A与C
- GPU1：B与D
- 每张A30同时两个约1GB进程
- Balanced wave结束后再启动Precision wave，降低CPU和磁盘争用

ABLATION_ROOT=runs/ocrap_v48_13_ablations \
ASSET_ROOT="$ASSET_ROOT" \
TRAIN_OCRAP_ROOT=/data0/senzeyu2/dataset/OCRAP \
EVAL_OCRAP_ROOT=/data0/senzeyu2/dataset/OCRAP \
INIT_CKPT="$BAL_CKPT" \
INIT_CKPT_BALANCED="$BAL_CKPT" \
INIT_CKPT_PRECISION="$PREC_CKPT" \
CALIBRATION_SEED=4801 \
PROPOSAL_TOP_K=3 \
GPU0=0 GPU1=1 \
BATCH_SIZE=72 ABLATION_NUM_WORKERS=3 PREFETCH_FACTOR=2 \
PREFERENCE_EPOCHS=14 PREFERENCE_PATIENCE=4 \
EVIDENCE_EPOCHS=12 EVIDENCE_PATIENCE=4 \
bash scripts/run_v48_13_parallel_ablations.sh \
  > runs/ocrap_v48_13_ablations.controller.log 2>&1 &

tail -f runs/ocrap_v48_13_ablations.controller.log
cat runs/ocrap_v48_13_ablations/ABLATIONS_STATUS.json
cat runs/ocrap_v48_13_ablations/ablation_summary_v48_13.json
