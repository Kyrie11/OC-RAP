OC-RAP v48.33 ELIGIBLE-SET-POLICY
下一轮实验执行指令（中文）

重要原则
========
1. 先只运行主实验。不要预先运行消融、shadow、test 或 stress。
2. v48.33 使用统一 top-5 proposal。因为 Stage-1 的监督和缓存合同包含 proposal_top_k，v48.32/v48.32.1 的 top-3 factor checkpoint 不允许复用；两个 variant 都需要重新训练 Stage-1。
3. 不要修改 GATE_SPEC 阈值，不要手工创建 NEXT_COMMANDS.txt，不要把 RC=30 当作算法结果。
4. Balanced 使用 GPU0，Precision 使用 GPU1。以下示例默认 GPU 0/1。

一、解压并进入代码目录
=====================

unzip -q OC-RAP-v48.33-ELIGIBLE-SET-POLICY.zip -d OC-RAP-v48.33
cd OC-RAP-v48.33
export PYTHONPATH="$PWD/src${PYTHONPATH:+:$PYTHONPATH}"

可选的快速本地检查：

python tools/check_v48_33_multigroup_loss_contract.py --output /tmp/V48_33_MULTIGROUP_LOSS_CONTRACT.json
bash -n scripts/run_v48_33_eligible_set_policy_dedicated.sh
bash -n scripts/calibrate_v48_33_certificate_pool.sh

二、只运行主实验
================

export OUTPUTDIR="runs/ocrap_v48_33_eligible_set_policy_dedicated_4833"
export OCRAP_ROOT="/data0/senzeyu2/dataset/OCRAP"

  >"$OUTPUTDIR.launcher.stdout.log" \
  2>"$OUTPUTDIR.launcher.stderr.log"

查看结构化状态：

三、严格按 RC 分支
==================

A. RC=30
-------

含义：工程、协议、训练、缓存、模型合同或 certificate artifact 失败。

立即停止。不要运行：
- v48.33 消融；
- adaptation-dev physical shadow；
- Safe paired；
- test；
- stress。

优先收集：

find "$OUTPUTDIR" -maxdepth 3 -type f \
  \( -name 'PIPELINE_FAILED.json' \
  -o -name 'VARIANT_STAGE_FAILED.json' \
  -o -name 'FAILURE_SIGNATURE_*.json' \
  -o -name 'TRAINING_CONTRACT.json' \
  -o -name 'METRIC_CALIBRATION_CONTRACT.json' \
  -o -name 'CALIBRATION_FAILED.json' \
  -o -name 'V48_33_COMPLETE.json' \) -print

tail -n 160 "$OUTPUTDIR/logs/adapt_balanced.log" 2>/dev/null || true
tail -n 160 "$OUTPUTDIR/logs/adapt_precision.log" 2>/dev/null || true
tail -n 200 "$OUTPUTDIR/logs/certificate_controller.log" 2>/dev/null || true

B. RC=20
-------

含义：pipeline 和 scene-disjoint certificate 有效，严格 Natural gate 已评估但未通过。
允许运行 v48.33 消融和 adaptation-dev physical shadow；仍禁止 test/stress。

先检查：

python - "$OUTPUTDIR/V48_33_COMPLETE.json" <<'PY'
import json,sys
x=json.load(open(sys.argv[1]))
assert x['pipeline_valid'] is True
assert x['certificate_executed'] is True
assert x['gate_evaluated'] is True
assert x['certificate_exit_code'] == 20
assert x['test_roots_read'] is False
print('RC20 authorization contract PASS')
PY

运行 8 个 v48.33 消融（每一波 Balanced/Precision 并行，Stage-1 精确复用主实验 top-5 factor）：

export MAIN_RUN="$OUTPUTDIR"

C. RC=0
------

含义：严格 Natural gate 通过。必须同时存在：
- $OUTPUTDIR/NEXT_COMMANDS.txt
- $OUTPUTDIR/NEXT_COMMANDS_STATUS.json，且 generated=true
- $OUTPUTDIR/V48_33_COMPLETE.json，且 gate_passed=true

检查并只执行生成的命令：

python - "$OUTPUTDIR/V48_33_COMPLETE.json" "$OUTPUTDIR/NEXT_COMMANDS_STATUS.json" <<'PY'
import json,sys,pathlib
complete=json.load(open(sys.argv[1])); status=json.load(open(sys.argv[2]))
assert complete['pipeline_valid'] is True
assert complete['certificate_executed'] is True
assert complete['gate_evaluated'] is True
assert complete['certificate_exit_code'] == 0
assert complete['gate_passed'] is True
assert complete['next_commands_generated'] is True
assert status['generated'] is True
assert pathlib.Path(pathlib.Path(sys.argv[1]).parent/'NEXT_COMMANDS.txt').is_file()
assert complete['test_roots_read'] is False
print('RC0 authorization contract PASS')
PY

cat "$OUTPUTDIR/NEXT_COMMANDS.txt"
bash "$OUTPUTDIR/NEXT_COMMANDS.txt"
