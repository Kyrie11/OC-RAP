OC-RAP v48.31 CONTRACT-SLACK-RANK 执行指令
=========================================

重要边界
--------

- v48.31 仍是一个统一 selector：Safe / Near-contact / Contact 不作为模型输入，也不路由到三套策略。
- Near / Contact 只用于数据划分、报告分层与 fail-closed 合同核验。
- 不得手工创建 NEXT_COMMANDS.txt，不得在 RC=20/30 时读取 test/stress。
- 请使用一个全新的 OUTPUTDIR，避免旧 checkpoint、旧 index 或旧 calibration 混入。

返回码语义：
- RC=0：Natural gate 有效通过，只执行自动生成的 NEXT_COMMANDS.txt；然后做 Safe paired non-inferiority 和 held-out stress。
- RC=20：有效算法拒绝，不读取 test/stress；执行第三节 adaptation-dev physical shadow 和第四节消融。
- RC=30：工程、协议、路径、索引、checkpoint、训练/推理合同、stage-transfer 或 certificate artifact 失败；不得做算法结论。

四组消融，每组 Balanced / Precision 各一项：
1. A_contract_natural_no_reliability_no_joint
2. B_add_support_reliability_no_joint
3. C_add_joint_refinement_no_reliability
4. D_full_contract_slack_rank

执行方式为四个 wave；每个 wave 仅并发两个任务：GPU0 Balanced、GPU1 Precision。
判读：B>A 隔离 support reliability；C>A 隔离 joint refinement；D>max(B,C) 才说明二者互补。
