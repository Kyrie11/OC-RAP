# V48.101 OC-RCSA 科学归因与 V48.102 OC-AITS 设计

## 0. 结论

V48.101 的实验结果工程上可靠，可以正式做算法归因，不需要 hotfix 或重跑。

正式科学判决：

```text
V48.101 OC-RCSA = ROOT_CROSS_ATTENTION_SEMANTIC_ALIGNMENT_STOP
```

但这不是“cross-attention 没用”的 STOP。V48.101 提供了目前最强的一组 support-establishment 正证据：相对 V48.100，support AUC 6/8 提升，true-vs-shuffle margin 8/8 提升，top-1 material lift 6/8；Near 两个 role 的支持建立明显改善。失败的关键是：这些 action-sensitive gain 没有与 static state 和 Contact reserve/debt generalization 同时成立。

因此本轮最重要的结论是：

> **Static recovery-state sufficiency does not imply action-response sufficiency, and action-sensitive root transport can improve candidate-specific support while degrading state organization and Contact reserve generalization.**

按照 V48.101 预注册后路，下一版不允许继续 decoder/source/capacity sweep，而应进入更上游的 Stage-I action-information transport sufficiency audit。

V48.102 已实现为：

```text
OC-AITS = Observation-Consistent Action-Information Transport Sufficiency Audit
```

它是 audit-only，不修改 planner。

## 2. 严格按 V48.101 preregistration：STOP

V48.101 不允许使用“相对 V48.100 有改善”替代绝对 GO gate。

### 2.1 State

State gate 要求 `AUC>=0.70` 至少 6/8、至少 3/4 role 且 Near+Contact。

V48.101：6/8，3 roles，正式 **GO**。

但它比 V48.100 的 8/8 明显退化：

| Variant | Role | V48.100 | V48.101 | Delta |
|---|---|---:|---:|---:|
| balanced | Dev Near | 1.000 | 0.143 | -0.857 |
| precision | Dev Near | 1.000 | 0.286 | -0.714 |
| balanced | Cert Near | 1.000 | 0.800 | -0.200 |
| precision | Cert Near | 1.000 | 0.700 | -0.300 |
| balanced | Dev Contact | 0.714 | 0.714 | 0.000 |
| precision | Dev Contact | 0.743 | 0.757 | +0.014 |

因此“State GO”不能解释为 static chart 更强；它只是仍跨过绝对 gate。

### 2.2 Support establishment

相对 V48.100：

| Variant | Role | V48.100 | V48.101 | Delta |
|---|---|---:|---:|---:|
| balanced | Dev Near | 0.398 | **0.695** | **+0.297** |
| precision | Dev Near | 0.438 | **0.750** | **+0.313** |
| balanced | Cert Near | 0.636 | **0.745** | **+0.109** |
| precision | Cert Near | 0.636 | **0.782** | **+0.145** |
| balanced | Dev Contact | 0.580 | 0.631 | +0.051 |
| precision | Dev Contact | 0.585 | 0.636 | +0.051 |
| balanced | Cert Contact | 0.612 | 0.603 | -0.009 |
| precision | Cert Contact | 0.671 | 0.602 | -0.070 |

此外：

```text
support AUC improved vs V100          6 / 8
support true-minus-shuffle improved   8 / 8

```

这明确证明 root cross-attention 是 support-establishment 的真实 causal transport primitive。

但完整绝对 gate 要求 `AUC>=0.65 && true-shuffle>=0.05` 至少 6/8、3 roles。实际只有四个 Near cells 满足，因此：

```text
support_action_representation_go = false
```

## 3. Dense semantic loss 为什么很重要

V48.101 相对 V48.100 的 dev semantic loss：

| Variant | Component | Relative change |
|---|---|---:|
| balanced | absolute support | -24.69% |
| balanced | delta support | -10.59% |
| balanced | absolute reserve | -4.10% |
| balanced | delta reserve | -10.85% |
| balanced | total | -13.37% |
| precision | absolute support | -24.39% |
| precision | delta support | -10.69% |
| precision | absolute reserve | -3.64% |
| precision | delta reserve | -9.59% |
| precision | total | -12.93% |

所以 cross-attention 并不是优化失败：它让四个 dense semantic objectives 全部变好。

但 discrete role gates 没有一起变好，state 还明显退化。这说明：

> **更低的平均 semantic regression error ≠ 一个能同时支持当前状态识别与 counterfactual action selection 的 control-sufficient statistic。**

V48.101 best epoch 在 16/17，之后 training loss继续下降而 dev loss回升。因此不存在“再加 epoch 就好”的合理解释。

---

## 4. Near-contact：support establishment 被改善了吗？

**被明显改善，但不是完整解决。**

Near 两个 role 是 V48.101 唯一同时跨过完整 support AUC+shuffle gate 的 roles。Dev-Near 的提升尤其大：`+0.297/+0.313`。

因此上一轮的 Near diagnosis：

> support establishment 是主要缺陷

得到**部分正验证**。

但新问题更加具体：

> cross-attention 为了让 action delta 可辨识，破坏了 dev-Near nominal state coordinate。

所以 Near 当前不再只是“support 不够”，而是：

```text
preserve current positive recovery state
AND
represent which candidate establishes/preserves common support
```

必须在同一个 observation-compatible coordinate 中同时成立。

这正是 unified mathematical object，而不是 Near-specific router。

---

## 5. Contact：generalization 稳定了吗？

**没有。**

Support：dev-Contact 小幅提高约 +0.051，但 certificate-Contact 没复制，precision 还下降约 -0.070。

Reserve：dev-Contact 明显下降，而 certificate-Contact 只从 ~0.417 小升到 ~0.44--0.47，且仍低于 shuffle。

因此 dev-to-certificate reserve gap 虽然数值变小，但主要因为 dev 变差，不是 certificate generalization 变好。

Contact 当前需要的仍是同一个 signed object：

```text
support establishment
+
negative recovery-debt repayment
+
dev -> certificate consistency
```

不需要 Contact policy/router。

## 6. 本轮值得 promotion / 保留什么

### Promotion 为 supported principle/scaffold

1. **Action-sensitive memory-to-root cross-attention is relevant.**
   6/8 AUC、8/8 shuffle-margin、6/8 top1 的 support 改善不是偶然噪声。
2. **Static base-state chart remains necessary.**
   V48.100 已有 8/8；V48.101 的 regress 证明 action dynamics 不能以牺牲 base state 为代价。
3. **Signed reserve/debt unified semantics.**
   继续统一 Near/Contact，不打开 router。
4. **Identifiability before capacity.**
   V48.101 已经把 decoder family定位到足够窄，下一步必须先查上游 Stage-I 信息充分性。

### 不 promotion

- V48.101 RCSA 作为 Main；
- root cross-attention head/rank/depth/width；
- K/V-only 或 Q/K/V fishing；
- V48.100/V48.101 state/delta learned mixing；
- source/boundary transport；
- broad encoder retraining；
- Near/Contact-specific attention；
- epoch/LR/loss-weight sweep。

## 7. 跨版本理论证据链

目前最关键的链条可以压缩为：

```text
V48.96
frozen roots contain real support-action information
but no stable joint state/reserve coordinate
        ↓
V48.97
static executable-recovery sufficient state becomes useful
        ↓
V48.98-99
a post-hoc tangent / state-conditioned Jacobian cannot make the frozen chart control-sufficient
        ↓
V48.100
joint root-query + semantic chart solves static state but barely moves delta-support
        ↓
V48.101
opening memory-to-root cross-attention materially repairs support-action ordering,
but damages Near state and does not generalize Contact reserve
        ↓
V48.102
locate whether the joint state/action statistic is already decodable before root decoding
```

理论上，这指向的不是“再加一个 feasibility head”，而是：

> **A deployable recovery representation must be a sufficient statistic for both the current recovery state and the action-conditioned transition of that state under the same observation-compatible information pattern.**

### 相关理论文献

- Gelada et al., *DeepMDP*, ICML 2019: jointly constraining latent state and latent transition preserves control-relevant structure. https://proceedings.mlr.press/v97/gelada19a.html
- Huang et al., *Action-Sufficient State Representation Learning for Control with Structural Constraints*, ICML 2022: in partially observed control, state representation should retain the information sufficient for action selection. https://proceedings.mlr.press/v162/huang22f.html
- Khetarpal et al., *A Unifying Framework for Action-Conditional Self-Predictive Reinforcement Learning*, AISTATS 2025: explicitly action-conditioned self-prediction leads to different representation dynamics from fixed-policy self-prediction. https://proceedings.mlr.press/v258/khetarpal25a.html
- Hamilton et al., *Efficient Learning and Planning with Compressed Predictive States*, JMLR 2014: predictive-state views formalize compact sufficient statistics for partially observable systems. https://jmlr.org/papers/v15/hamilton14a.html
- Xiao et al., *Action-based Representation Learning for Autonomous Driving*, CoRL 2020/PMLR 2021: action-based supervision can improve driving representation quality and reduce spurious correlations. https://proceedings.mlr.press/v155/xiao21a.html

这些工作提供的是理论支撑，不替代 OC-RAP 自己的 preregistered evidence chain。

## 8. 距离内部收敛的变化

### Functionally

不能说已经“明显接近最终收敛”：

```text
V48.100 complete cells roughly: State 8 / Support 1 / Reserve 5
V48.101 complete cells roughly: State 6 / Support 4 / Reserve 5
```

Support gap 明显缩小，但 State margin 被消耗，Reserve 没跨过阈值。

所以它不是单调 function improvement。

### Scientifically

**距离内部收敛在机制定位上明显缩短。**

目前剩余开放层已经从“大模型/feasibility source 不行”收敛为：

```text
Stage-I structured memory
    -> action/state sufficient statistic?
    -> root transport?
    -> final source
```

也就是只剩 representation hierarchy 的一处核心分叉。

在 absolute/control-sufficient representation GO 之前，仍然不应正式打 external SOTA baseline。

## 9. 为什么现在必须进入 Stage-I audit

V48.101 的 preregistered next branch 已经锁定：

```text
close root decoder semantic family
-> Stage-I action-information transport sufficiency audit
-> no capacity/source sweep
```

直接设计 dual-attention、state/delta mixture、new source 或 broad encoder 都会违反当前证据顺序。

理论上，root decoder 是 Stage-I memory 的 deterministic downstream transform。按 data-processing principle，真正不存在于上游的信息不能被下游凭空创造；但一个 downstream nonlinear map 可以改变**可解码性**。因此下一轮最有价值的问题不是“mutual information 是否绝对为零”，而是：

> **V48.93 support/reserve target semantics 是否已经从 frozen Stage-I memory 以固定低容量方式可解码？**

这正是 V48.102。

## 10. V48.102 OC-AITS

### 10.1 不改 planner

```text
planner params trained       0
Stage-I params trained       0
root decoder params trained  0
source params trained        0
boundary transport           OFF
relative ranker              frozen
regime ID                    NO
dataset reconstruction       NO
```

### 10.2 Stage-I summary

StructuredTokenEncoder 输出：

```text
CLS
+ 10 fixed semantic tokens
+ agent token set
```

V48.102：

- 保留 `CLS + 10 fixed semantic positions`；
- agent set 只做 `mean/std/max/min` permutation-invariant moments；
- `d=192` 时固定维度：`(11+4)*192 = 2880`；
- 不引入 learned memory encoder、agent ID、root ID、option ID 或 regime ID。

同一 scene-time：

```text
state   = z(a0)
delta   = z(a) - z(a0)
context = delta * (1 + tanh(state))
```

### 10.3 Target semantics

完全复用 V48.96/V48.93：

- State: nominal DRS-activation vs deployability-gain mode；
- Support: DRS-activation stratum 内 safe support-establishing action vs harmful；
- Reserve: deployability-gain stratum 内 safe reserve/debt action vs harmful；
- support/reserve 都有 within-scene-time action shuffle null control。

V48.102 强制与 V48.101 evaluation population 的 row/class/group counts exact identity。

### 10.4 Gates

仍是：

```text
State >=0.70, >=6/8, >=3 roles, Near+Contact
Support >=0.65 && true-shuffle >=0.05, >=6/8, >=3 roles,
        top1 >=+0.10 >=4/8, Near+Contact
Reserve same
```

### 10.5 下一分支

**Stage-I full GO**：说明 upstream memory 已具 jointly decodable statistic，root decoder family 是 transport bottleneck；下一版只允许一次 direct memory-to-recovery semantic transport，不开 source/capacity sweep。

**Stage-I partial**：说明信息只在部分 support/reserve axis 成立；下一版只允许 minimal Stage-I recovery-sufficient representation objective。

**Stage-I STOP**：说明问题真的已经上移到 Stage-I representation objective；仍不允许 broad encoder/source sweep。

## 11. Main Stack

当前 Main Stack 不替换：

```text
OC-MERO observation-consistent deployability
+ actuator-realizable executable recovery
+ counterfactual equivalence-partition transport
+ identifiability before capacity
```
