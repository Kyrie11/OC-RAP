## 二、V48.102 结果详细归因

### 1. State

Stage-I summary 的 nominal-state AUC：

| role | AUC |
|---|---:|
| Dev Near | 0.2857 |
| Dev Contact | 0.6286 |
| Certificate Near | 0.0000 |
| Certificate Contact | 0.7321 |

balanced/precision 完全一致。

只有 certificate-Contact 达到 0.70，因此 state GO 明确失败。

这与 V48.100/V48.101 的结果组合后非常有信息：V48.100 的 root semantic chart 能把 state 做到 8/8 GO，V48.101 仍能保持形式上的 state GO，但在 Stage-I fixed summary 上 state 并不直接线性可解码。也就是说，root decoder 不是一个被动 readout；它在实际构造/重组织部分 recovery-state semantics。

### 2. Support establishment

| role | true AUC | shuffled AUC | margin | top1 lift |
|---|---:|---:|---:|---:|
| Dev Near | **0.8125** | 0.5078 | **+0.3047** | **+0.60** |
| Dev Contact | 0.6364 | 0.6023 | +0.0341 | +0.1667 |
| Certificate Near | 0.6182 | 0.2727 | **+0.3455** | +0.3333 |
| Certificate Contact | 0.4522 | 0.5774 | **-0.1252** | +0.10 |

最强正信号是 dev-Near。这说明 Near 的 candidate-specific support cue 已经存在于更上游 Stage-I memory 中，并不是只有 cross-attention 训练后才“凭空产生”。

但它没有形成跨 role 稳定的 sufficient statistic：

- dev-Near 很强；
- dev-Contact 接近门槛但 true-vs-shuffle 不够；
- certificate-Near 有很强 shuffle separation，却 absolute AUC 不够；
- certificate-Contact 直接反向。

因此真正缺的是 **cross-split / cross-regime semantic consistency**，而不是“完全没有 support 信息”。

### 3. Reserve / debt

| role | true AUC | shuffled AUC | margin | top1 lift |
|---|---:|---:|---:|---:|
| Dev Near | 0.7500 | 0.6250 | +0.1250 | 0 |
| Dev Contact | 0.5521 | 0.6406 | -0.0885 | 0 |

| Certificate Contact | 0.5556 | 0.6944 | -0.1389 | -0.25 |

所以 Stage-I reserve/debt 不是一个稳定可用的 action statistic。Contact 尤其明显：dev 与 certificate 都弱，而且相对 shuffle 为负。

## 三、V48.101 → V48.102 的 layer-localization 结论

V48.102 comparison 直接记录 Stage-I 与 V48.101 root-semantic AUC 的差异。

### Support

- Dev Near: Stage-I `0.8125`，高于 V48.101 `0.695/0.750`；
- Dev Contact: Stage-I `0.636`，与 V48.101 基本相同；
- Certificate Near: Stage-I `0.618`，低于 V48.101 `0.745/0.782`；
- Certificate Contact: Stage-I `0.452`，低于 V48.101 `~0.60`。

因此 cross-attention 的作用不是单向“恢复信息”：

- 它会损失一部分 local dev-Near cue；
- 但能重新组织出 certificate-Near / certificate-Contact 的一些 generalizable support semantics。

### State

Stage-I state 在大部分 role 比 V48.101 更差，尤其 certificate-Near 从 `0.7–0.8` 降到 `0.0`。

因此 static recovery state 主要是在 downstream root representation 中被组织出来的，而不是一个 Stage-I summary 上现成的 linear coordinate。

### Reserve/debt

Stage-I reserve 在 dev-Contact/certificate-Near 明显低于 V48.101；certificate-Contact 略高但仍低质量。因此 downstream root transport 对 reserve 有局部构造作用，但没有形成稳定 generalization。

## 四、理论结论：继续沿着 `static sufficiency != control sufficiency`

是，而且 V48.102 使这条结论更强。

V48.100–102 现在构成：

1. V48.100：static recovery chart 可以做强；
2. V48.101：打开 action-sensitive cross-attention 可恢复 support-action signal，但会破坏部分 static state，并且 Contact reserve generalization 仍失败；
3. V48.102：更上游的 Stage-I fixed summary 也不存在一个同时跨 State/Support/Reserve GO 的 linear sufficient statistic。

所以最终论文不应该把 control-sufficient representation 写成一个“更好的 state encoder”。更准确的是：

> 一个 deployable recovery state 必须同时对 current recovery state 与 action-conditioned recovery dynamics 充分。

可写为：

`Z_ctrl(o,a) = S(o) ⊕ Delta(o,a;a0)`，

其中：

- `S(o)` 保持 nominal recovery state；
- `Delta(o,a;a0)` 表达 candidate-induced support establishment / reserve-debt change；
- 两者最终组合到同一 D/R recovery coordinate，但不应由同一 unconstrained transport update 相互覆盖。

外部理论支撑：

- Gelada et al., DeepMDP, ICML 2019：control-relevant representation 通过 reward / latent transition objectives 联合约束，而不仅是静态压缩；
- Huang et al., Action-Sufficient State Representation Learning, ICML 2022：在部分观测下寻找对 downstream decision-making 足够的最小 state representation；
- Khetarpal et al., Action-Conditional Self-Predictive RL, AISTATS 2025：理论分析显式 action-conditioned self-predictive objective；
- Predictive State Representation / partially observable representation literature：可观测历史的 sufficient statistic 应服务未来受 action 条件化的预测/控制，而不是恢复不可部署 hidden state；
- Lee et al., Set Transformer, ICML 2019：attention pooling 是从 token/set 结构提取 permutation-compatible semantic statistic 的合理工具。

这些工作只提供理论原则；V48.103 的科学授权来自 OC-RAP 自己的 V48.96–102 因果链。

## 五、V48.102 能否回答“cross-attention 输入里到底有没有同时支持三任务的 sufficient statistic？”

严格答案必须分两层。

### 注册意义：NO

在 preregistered 固定 representation：

`CLS + 10 semantic tokens + agent mean/std/max/min -> 2880-D -> linear probe`

下，没有任何 State/Support/Reserve gate GO，因此不存在一个满足注册标准的 **jointly linearly decodable sufficient statistic**。

这足以否定：

> “Stage-I 已经完整足够，只是 V48.101 cross-attention 写错了。”

### 信息论意义：尚不能证明 NO

V48.102 先对 43×192 token memory 做了 summary，再线性 probe。raw tokenwise interaction 可能在 summary 中丢失。因此 V48.102 不能证明：

`I(full Stage-I memory ; control-sufficient recovery object) = 0`。

这正是 V48.103 设计成“full-token minimal nonlinear semantic representation”的原因，而不是直接 broad-encoder retrain。

## 六、Near / Contact 当前主要问题

### Near-contact

正向结果：

- Stage-I dev-Near support AUC 0.8125；
- V48.101 cross-attention 也大幅改善 Near support；
- 说明 support establishment signal 已经出现，而且不是偶然无信息问题。

当前缺陷：

1. static state 与 support-response 无法在同一 representation 中稳定共存；
2. dev-Near 的强 cue 在 certificate-Near 降到 0.618，存在 generalization gap；
3. reserve/debt action 信号不稳定。

Near 的统一目标仍是：

> 保持/建立 positive lower-tail recovery support/headroom。

### Contact

当前问题更严重：

- Stage-I dev-Contact support 只有 0.636，shuffle margin +0.034；
- certificate-Contact support 0.452，反向于 shuffle；
- reserve dev/certificate 都低于 shuffle；
- V48.101 也没有真正解决 certificate reserve/debt generalization。

Contact 当前主要缺陷是：

> 表示没有把 candidate action 对 negative recovery debt 的偿还作用组织成跨 held-out scene 稳定的 semantic response。

仍然不需要 Contact router。统一 object 保持：

`Near: positive reserve/headroom`

`Contact: negative debt -> repayment -> re-entry positive side`。

## 九、V48.103 OC-FCSS

全称：

**Observation-Consistent Factorized Control-Sufficient State**。

### 设计动机

V48.102 all-STOP 后，预注册允许一个最小 Stage-I recovery representation objective，但不允许 broad encoder/source sweep。

同时 V48.102 的固定 summary 有信息损失 caveat，因此最干净的下一问是：

> full frozen Stage-I token set 能不能通过一个很小、显式 factorized 的 semantic bottleneck形成 control-sufficient D/R representation？

### 结构

对 frozen Stage-I memory `M(o,a) ∈ R^{T×d}`，学习 4 个 content-addressed semantic query：

1. nominal support state；
2. nominal reserve/debt state；
3. support response potential；
4. reserve/debt response potential。

每个 channel 只有：

- query `[d]`；
- readout `[d]`；
- bias `[1]`。

`d=192` 时总参数：

`4 × (192+192+1) = 1540`。

没有 MLP、rank、width、expert、root/option/regime ID、source residual 或 learned state/delta mixture。

### Factorized composition

对 group nominal `a0`：

`D(a) = sigmoid(S_D(M(a0)) + U_D(M(a)) - U_D(M(a0)))`

`R(a) = S_R(M(a0)) + U_R(M(a)) - U_R(M(a0))`。

性质：

- nominal action response exact zero；
- candidate response 无法通过改变 nominal base state 作弊；
- static state 和 action response 参数通道分离；
- 最终仍落到同一个 D/R semantic coordinate；
- Near/Contact 无 router。

### Supervision

继续使用 V48.100 的四项 dimensionless semantic objective：

- absolute D；
- absolute R；
- candidate-minus-nominal DeltaD；
- candidate-minus-nominal DeltaR。

复用 train-only fixed semantic RMS scales，不 sweep。

### Evaluation

继续 exact reuse V48.102 / V48.101 / V48.100 / V48.96 的 target-specific evaluation population、within-group shuffle 和 GO gates。

### 分支

- Full GO：授权一次 production semantic-token transport integration；
- State+Support GO/Reserve STOP：仅允许 supported reserve-flow objective；
- State+Reserve GO/Support STOP：仅允许 support-establishment objective；
- 其他 STOP：关闭 frozen Stage-I readout family，下一层只允许最后一个 Stage-I transformer block 的 control-sufficient objective，不开 broad encoder/source。

## 十、投稿层面的最关键结论

本轮后，论文最有价值的 theoretical statement 可以进一步写成：

> **Recoverability requires a control-sufficient representation, not merely a statically predictive one. Under a deployable observation pattern, the representation must preserve both a nominal recovery sufficient state and candidate-induced signed support/reserve dynamics without allowing one to overwrite the other.**

这条 statement 已由 V48.100–102 的连续负/正证据支持：

- static chart 可以成功；
- action transport 可以局部成功；
- 但 shared unconstrained representation 会 trade off state 与 response；
- frozen Stage-I summary 也没有现成的 joint linear sufficient statistic。

V48.103 用固定 1540 参数直接检验这个理论，而不是再堆一个 feasibility head。
