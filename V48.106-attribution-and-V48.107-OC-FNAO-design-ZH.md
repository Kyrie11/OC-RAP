## 3. 本轮最关键的新结论

### 3.1 action information 已存在，但不等于 joint control sufficiency

pre-encoder 表示在不经过任何 Transformer mixing 时，global 三轴都不充分；因此不能把 projected token set 本身视为 control-sufficient state。

但 fixed action-interaction subspace 的 reserve/debt 已正式 GO。两套 variant 中正 cell 都是：

- dev-Near；
- certificate-Near；
- certificate-Contact。

这说明 reserve/debt response 并非必须由 Transformer 从零“创造”。上游 projected control / scene / agent coordinates 已包含真实可迁移结构。

### 3.2 Support 是更主要的 transfer 缺口

同一 action-interaction subspace 下，Support 只有 dev-Near / dev-Contact 四个 cell 为正，certificate transfer 不成立。Global pre-encoder Support 也只有 dev-Near 正式过门。

所以当前 dominant response bottleneck 已收紧为：**support-establishment 的跨 population signed orientation**，而不是“模型是否能感知 action”。

### 3.3 V48.105 的 CKA 矛盾得到 signed 解释

V48.106 新增的 diagnostic-only orientation cosine 明确区分了 magnitude association 与 signed transfer。

- reserve action-interaction：mean CKA-minus-shuffle 约 +0.405，但 mean signed cosine 仅约 +0.114；
- support action-interaction：mean signed cosine 约 +0.010，仅 4/8 cell 同向；
- support ego/history：mean signed cosine 约 +0.680，8/8 同向。

因此高 CKA/energy 不等于 equivariance。真正控制充分的表示必须保留 candidate response 的符号与排序方向。

### 3.4 第一个 Transformer block 的物理作用已经被定位

V48.106 的 architectural diagnostics 表明 candidate-induced 信息大量存在于 prefix/ego-history coordinates，同时 reserve/debt 在 action-interaction subspace 已有良好信号。这意味着 block 1 的合理职责不是增加通用 capacity，而是把：

`candidate prefix state change + control + scene/agent interaction`

组合成一个可迁移的 signed recovery-response coordinate。

这与真实规划过程一致：动作的价值通过可执行 prefix/ego rollout 与环境交互改变 recoverability，而不是只存在于一个抽象 control token。

## 4. V48.100--106 因果链

1. V48.100：static recovery state 可稳定学习，但 action support 很弱。
2. V48.101：打开 action-sensitive root transport 能恢复 support，但会破坏 static state。
3. V48.102：final Stage-I 有局部 action cues，却没有 joint State+Support+Reserve statistic。
4. V48.103：state/response 参数 factorization 能恢复 static state，但 response geometry 仍不稳定。
5. V48.104：hard nominal invariance + response-only learning 可以同时降低 delta-support / delta-reserve loss，证明 state preservation 与 response learning 可兼容；但 cross-cell gate 仍 STOP。
6. V48.105：pre-last 表示已有强 action association，却缺 signed transfer；最后 block 既有 constructive effect，也无法独自解决 orientation。
7. V48.106：在任何 Transformer 之前，reserve/debt 已局部/子空间充分，support transfer 不充分；整个 frozen layer-location ambiguity 已关闭。

因此 durable theory 进一步收敛为：

`static sufficiency != control sufficiency`

`parameter factorization != representation factorization`

`response-loss reduction != cross-distribution control sufficiency`

`action association != signed action equivariance`。

## 5. Near / Contact 当前瓶颈

### Near

Nominal-state preservation 已由 V48.103/V48.104 的 exact anchoring 基本解决。pre-encoder dev-Near support 为真实正信号，且 action-interaction reserve 甚至达到非常强的排序；但 global reserve 可完全 wrong-sign。这说明 Near 不再是“如何同时保护 state 和 response”，而是：

**如何把已经存在于不同 token/pathway 的 support-establishment 与 positive-reserve response 组合成同一个 signed candidate direction。**

### Contact

pre-encoder dev-Contact support 接近正式阈值且有真实 shuffle margin，但 certificate support 弱。reserve 在 fixed action-interaction 中 certificate-Contact 非常强，而 dev-Contact 仍不过门。当前 Contact 缺口是：

**interaction/debt 信息存在，但在 dev/certificate 间仍没有一个统一 signed orientation。**

Near 与 Contact 可以继续用同一数学对象：`Delta recovery(a)=recovery(a)-recovery(a0)`；Near 向正 reserve 建立，Contact 沿同一正方向偿还负 debt。无需 regime router。

## 8. V48.107 OC-FNAO

全称：**Observation-Consistent First-Block Nominal-Invariant Action Orientation**。

### 8.1 只训练第一个历史 Transformer block

Trainable：block 1，d=192 时 444,864 parameters。

Frozen：

- input projections / positional embeddings；
- block 2 + final norm；
- V48.103 FCSS readout 1,540 params；
- root decoder / source / planner / relative ranker。

### 8.2 Exact nominal invariance

设 projected input tokens 为 `H0(a)`，历史第一 block 为 `B0`，adapted copy 为 `Btheta`：

`Etheta(a)=Btheta(H0(a))-B0(H0(a))`

`H1theta(a)=B0(H0(a))+Etheta(a)-Etheta(a0)`。

因此 nominal row 的 block-1 output 精确保持历史值。冻结 block2 后，最终 nominal memory 也在接口上强制精确保持 V48.103 baseline，防止任何 action objective 再次通过破坏 static state 买到收益。

### 8.3 不再重复 response Huber，而改成 ordinal orientation objective

V48.104 已证明 response Huber 可以下降但 held-out ranking 仍未闭合。V48.106 又证明真正缺陷是 signed ordering transfer。因此 V48.107 对每个 scene-time group 内所有 teacher response 不同的 pair 只取目标顺序符号：

`sign(y_i-y_j)`。

预测 pair 用：

`p_i-p_j`。

损失：

`softplus(-sign(y_i-y_j)*(p_i-p_j)/frozen_delta_scale)`。

Support 与 Reserve 两轴等权；teacher magnitude 在确定 pair sign 后丢弃。这样目标更直接对应 AUC / top-1 action selection，同时减少不同 population calibration scale 对训练的影响。

这不是“ranking 一定保证 OOD”的理论宣称。Pairwise surrogate 本身仍需 held-out gate 验证；它只是把训练 objective 从 magnitude calibration 收紧到当前实验真正缺失的 **signed action ordering**。

### 8.4 不引入新自由度

没有新 head、query、rank、width、token router、regime id 或 source residual；没有 loss-weight sweep；LR/epoch/patience 沿历史固定值，不做 sweep。

## 9. V48.107 预注册 gate

- Support / Reserve：AUC >=0.65 且 true-shuffled >=+0.05，>=6/8，>=3/4 roles，Near+Contact；top1 lift >=+0.10，>=4/8 且 Near+Contact。
- Full GO = State AND Support AND Reserve。
