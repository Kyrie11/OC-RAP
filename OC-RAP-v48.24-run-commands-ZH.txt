五、RC=20 后先检查结构支持与 learned frontier
---------------------------------------------

python - "$OUTPUTDIR" <<'PY'

    for regime in ('near','contact'):

        d=json.load(open(p))
        print('\n===',variant,regime,'===')
        print('valid_for_deployment =',d.get('valid_for_deployment'))
        print('proposal_support_curve =')
        print(json.dumps(d.get('proposal_support_curve'),indent=2))
        print('active oracle =')
        print(json.dumps(d.get('proposal_constrained_oracle_gate'),indent=2))
        print('learned corr =',d.get('proposal_evidence_top1_correlation'))
        print('learned safe-benefit AUC =',d.get('proposal_evidence_top1_safe_positive_auc'))
        print('conditional harm AUC =',d.get('proposal_evidence_top1_conditional_harm_auc'))
        print('harmful switch =',d.get('proposal_evidence_harmful_switch_rate'))
        print('positive regret =',d.get('proposal_evidence_positive_top1_regret_mean'))
        print('nearest fit frontier =')
        print(json.dumps(d.get('near_miss_frontier'),indent=2))
PY

判读：

1. k=8 fit/verify oracle 都 pass，但 learned fail：问题仍在 safe-utility 表示、排序或 finite-sample admission。
2. k=3 fail、k=8 pass：扩大支持有效，重点比较 B/C/D 消融。
3. k=8 仍 fail：固定数据、标签、proposal 连续参数与 gate 合同仍不兼容；不要重复 calibrator。

四组：

A_top3_safe_label_baseline
  top-3 + safe-benefit 标签；隔离标签语义。

B_top8_support_only
  A + top-8；隔离 proposal 安全支持宽度。

C_top8_safe_utility
  B + direct continuous safe-utility regression/listwise。

D_full_support_bridge
  C + 轻量 high-benefit safety-frontier contrast。

调度方式：四个 wave；每个 wave GPU0 跑 Balanced、GPU1 跑 Precision；最大并发 2，
每张 A30 总计 4 个任务，不会像四进程同卡那样争抢显存和 host 线程。

八、最终判读
------------

B>A：safe-positive 位于 raw-benefit top-3 之外，support width 是关键。
C>B：direct safe-utility 学习有效，v48.23 的间接 benefit/harm 组合是主缺陷。
D>C：frontier contrast 有额外价值；若 D 不优于 C，主模型应使用 C 的简化版本。
Oracle pass + 离线改善 + dev shadow 不改善：teacher/features 与物理闭环错位。
Oracle pass + dev shadow改善 + gate fail：有限样本证书可能过保守，只能在后续新版本预注册支持协议，不能事后调当前 gate。
Oracle k=8 fail：停止模型调参；需要重新设计 proposal 连续参数、safe-positive 标签或新增证书支持数据。
